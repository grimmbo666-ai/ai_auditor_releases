# AI Auditor — тестовые сборки

Этот публичный репозиторий содержит только установщики AI Auditor, контрольные суммы и заметки к версиям. Исходный код хранится отдельно.

## Важно

Предварительные сборки предназначены только для ознакомительного тестирования и не являются коммерческим релизом. Текущая Windows-сборка не подписана сертификатом издателя и не проверена на чистой Windows 10/11. Русский OCR требует Tesseract с `rus.traineddata`; см. инструкции конкретного релиза. Юридические документы продукта остаются шаблонами.

Перед запуском скачивайте файлы только со страницы GitHub Releases этого репозитория и сверяйте SHA-256 из `checksums.txt`. Не используйте тестовые сборки для критичных или конфиденциальных документов.

## Тестирование и обратная связь

Тестируйте сборку на копиях или обезличенных документах. После проверки сообщите, пожалуйста, версию Windows (10/11 и разрядность), способ запуска (установщик или portable), шаги воспроизведения и ожидаемый/фактический результат. Не прикладывайте исходные документы, персональные данные, ключи или другую конфиденциальную информацию.

Для сообщения об ошибке создайте [Issue](https://github.com/grimmbo666-ai/ai_auditor_releases/issues/new) и укажите `v1.0.1-preview.1` в заголовке. Если приложение завершилось с ошибкой, добавьте текст ошибки и относящиеся к ней строки журнала, предварительно удалив персональные данные. Сообщения об ошибках не являются каналом срочной поддержки.
